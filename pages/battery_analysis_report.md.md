- ## 🔴 關鍵發現：電池日曆老化是主因
  
  CAUTION
  
  **你的「新電池」實際上已經老化了 11 年！**
  這不是 AlDente 設置造成的問題，而是**電池庫存過久**的後果。
- ### 科學依據（Battery University）
  
  鋰離子電池存在兩種老化機制：
  
  | 老化類型 | 說明 | 你的情況 |
  | ---- | ---- | ---- |
  | **循環老化** (Cycle Aging) | 充放電次數累積導致的損耗 | ✅ 僅 4 次，可忽略 |
  | **日曆老化** (Calendar Aging) | 電池即使不使用，化學成分也在持續衰退 | ❌ **11 年**，遠超建議值 |
  
  **Battery University 建議的鋰電池保質期**：
- 理想存放條件下：**3-12 個月**
- 最長可接受：**2-3 年**
- 你的電池存放時間：**≈ 11 年** ❌
- ### 為何 coconutBattery 顯示 100% 健康？
  
  ```
  
  ```
  
  **解釋**：
- **coconutBattery** 只能讀取電池控制器回報的「最大容量」數值
- **Apple Diagnostics** 進行更深層的硬體測試，包括：
	- 內阻測量
	- 電壓穩定性
	- 充放電曲線分析
	- 電芯一致性檢查
	  
	  一塊老化的電池可能「看起來」容量正常，但**內阻升高、電壓不穩、電芯衰退不均**——這些問題只有深層診斷才能發現。

- ## 🔍 Apple Diagnostics 錯誤碼解讀
- ### PPP005：充電器瓦數不匹配
  
  | 項目 | 你的情況 |
  | ---- | ---- | ---- |
  | **你使用的充電器** | 60W |
  | **MBP 15" (2015) 需要的** | **85W** |
  | **診斷結果** | ⚠️ 偵測到瓦數不足 |
  
  IMPORTANT
  
  **這不一定會損壞電池，但會影響診斷精確度。**
  Apple Diagnostics 建議使用正確瓦數的充電器重新測試。
  
  **實際影響**：
- 60W 充電器可以為 MBP 15" 慢速充電
- 但在高負載時（如跑影片剪輯），可能**邊充邊掉電**
- 診斷時使用錯誤瓦數可能導致誤判
- ### PPT004：電池需要維修
  
  | 嚴重程度 | 說明 |
  | ---- | ---- | ---- |
  | **警告級** | 電池仍可使用，但效能已下降 |
  | **建議** | 觀察續航力變化，若急劇下降則更換 |
  
  **可能原因**（根據你的情況）：
- ✅ **日曆老化**（最可能）：電池存放 11 年，內部化學成分已衰退
- ⚠️ 商家庫存管理不當：可能存放環境不佳（高溫、高電量狀態）
- ❓ 第三方電池品質問題：OEM 副廠電池品控不一

- ### 📌 辨別真偽的關鍵問題
- **這個說法有沒有可驗證的證據？**
	- ✅ 好例子：「Battery University 研究顯示，充電到 4.10V 可將壽命延長一倍」
	- ❌ 壞例子：「我覺得睡眠比關機好」
- **發言者有沒有利益衝突？**
	- ⚠️ AlDente 開發者說「你需要我的 App」→ 利益相關
	- ✅ 獨立研究機構的數據 → 較客觀
- **這是相關性還是因果性？**
	- 「我用了 AlDente 後電池健康維持 100%」→ **相關性**
	- 「因為 AlDente 限制充電，所以電池健康好」→ **因果性**（需要對照組驗證）
- **樣本量夠不夠大？**
	- N=1 的個人經驗 → 只能當參考
	- 多人長期追蹤 + 對照組 → 可信度高
