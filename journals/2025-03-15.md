	- 恢复 Mac  自动 git push
		- ### **检查 `.git/hooks` 是否存在**
		  
		  ```
		  ls -la /Users/mac/Documents/Logseq-sync/Sync-Logseq/.git/
		  ```
		- ### **进入 hooks 目录**
		  
		  ```
		  cd /Users/mac/Documents/Logseq-sync/Sync-Logseq/.git/hooks
		  ```
		- ### **2. 创建 `post-commit` 钩子**
		  
		  ```
		  touch post-commit
		  ```
		- ### **3. 编辑 `post-commit` 并添加以下内容**
		  
		  ```
		  nano post-commit
		  ```
		  
		  然后粘贴以下代码：
		  
		  ```
		  #!/bin/bash
		  git push origin main
		  ```
		  
		  按下 `Control + X` → `Y` → `Enter` 保存退出。
		- ### **4. 赋予执行权限**
		  
		  ```
		  chmod +x post-commit
		  ```
		  
		  ---
		- ### **测试**
		  
		  回到 Logseq 仓库目录：
		  
		  ```
		  cd /Users/mac/Documents/Logseq-sync/Sync-Logseq
		  ```
		  
		  然后尝试：
		  
		  ```
		  echo "Test auto commit" >> test.txt
		  git add test.txt
		  git commit -m "Testing auto push"
		  ```
		  
		  如果设置正确，`post-commit` 钩子会自动执行 `git push origin main`，你应该会看到类似：
		  
		  ```
		  Enumerating objects: 3, done.
		  Counting objects: 100% (3/3), done.
		  Writing objects: 100% (3/3), 253 bytes | 253.00 KiB/s, done.
		  Total 3 (delta 0), reused 0 (delta 0)
		  To https://github.com/GengGeng026/Sync-Logseq.git
		   abc1234..def5678  main -> main
		  ```
		  
		  这样，每次 `commit` 之后都会自动 `push`，你的 Mac 和 iPhone（使用 Working Copy）就能实时同步 Logseq 的内容了！
