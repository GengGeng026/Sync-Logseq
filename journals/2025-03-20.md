		- 輸入指令 ``cat /Users/mac/Documents/Sync-Logseq/auto_sync.sh``  後，返回：
			- > #!/bin/bash
			  <br />
			  进入 Sync-Logseq 目录
			  cd /Users/mac/Documents/Sync-Logseq
			  >
			  无限循环，每 15 秒检查一次
			  while true; do
			  >
			  输出当前时间，记录同步开始时间
			   echo "Sync started at $(date)" >> $LOG_FILE
			  >
			  拉取远程仓库的更新
			   echo "Pulling changes..." >> $LOG_FILE
			   git pull origin main >> $LOG_FILE 2>&1
			  >
			  检查是否有更新，并提交
			    commit_message=$(git diff --staged --oneline)
			    if [ -n "$commit_message" ]; then
			        echo "Changes detected, committing..." >> $LOG_FILE
			        git commit -m "Changes: $commit_message" >> $LOG_FILE 2>&1
			        git push origin main >> $LOG_FILE 2>&1
			    else
			        echo "No changes detected" >> $LOG_FILE
			    fi
			  >
			  输出同步完成时间
			  echo "Sync completed at $(date)" >> $LOG_FILE
			  >
			  暂停 15 秒
			  sleep 15
			  >
			  done
		- 問題 1：腳本可能無執行權限
		  logseq.order-list-type:: number
			- 執行指令
			  > chmod +x /Users/mac/Documents/Sync-Logseq/auto_sync.sh
		- 問題 2：git diff --staged 不會檢查未追蹤的文件
		  logseq.order-list-type:: number
		  > commit_message=$(git diff --staged --oneline)
			- 這樣的寫法**只能檢查已經 `git add` 過的變更**，但如果 Logseq 生成了新文件（如 journal），這些文件可能**還沒被 `git add`**，導致腳本不會提交它們。
			- ✅ **修正方式**：
			  > commit_message=$(git status --porcelain)
		- 問題 3：缺少 `git add`，導致新文件未被追蹤
		  logseq.order-list-type:: number
			- 腳本中**沒有 `git add .`**，這意味著 Logseq 生成的新文件（如 journal）不會被 Git 追蹤，自然也不會提交。
			- ✅ **修正方式**：
			  請在 `git commit` 之前加上：
			  > git add .
